# `.shooter/` Directory Guide

This directory contains all shooter configuration, project data, and AI agent context for this repository.

## Files

| File | Purpose | Owner |
|------|---------|-------|
| `project-alias.txt` | Short project alias used in commit scopes and beads | Human |
| `project-version.txt` | Current SemVer version, bumped per-commit | AI (patch), Human (minor/major) |
| `shooter-labels.json` | Generated label definitions — DO NOT EDIT | Generated |
| `combined-rules.json` | Ordered list of rule file paths compiled into agent files | Generated (merge of template + project) |
| `project-command-log.jsonl` | Usage log of shooter command invocations | Generated |
| `project-context.md` | Merged human + AI learnings — compiled into CLAUDE.md | Human (§ Human Notes), AI (§ AI Learnings) |
| `project-decisions.md` | Architectural decisions log (newest first) | AI (appends after bead close) |
| `project-glossary.md` | Project-specific terms and abbreviations — compiled into CLAUDE.md | Human |
| `project-labels.json` | User-extended label definitions (project-specific) | Human |
| `project-progress.md` | Auto-generated progress dashboard from beads | Generated |
| `project-q-and-a.md` | Persisted Q&A from agent sessions (newest first) | AI |
| `project-themes.json` | Theme definitions (slug, title, path, shotfile) | Human / `shooter:add-theme` |
| `.gitignore` | Ignores `tmp/` directory | Generated |

## Directories

| Directory | Purpose | Owner |
|-----------|---------|-------|
| `project-codebase/` | Per-theme codebase analysis documents | Generated by `shooter:map-codebase` |
| `project-config/` | Shooter configuration files (hooks, settings) | Generated by `shooter:setup` |
| `project-debug/` | Temporary debug output | AI |
| `project-plans/` | Execution plans for shooter tasks | AI |
| `project-research/` | Research documents on specific topics | AI |
| `project-rules/` | User rule extensions (project-specific rules) | Human |
| `shooter-rules/` | Copies of rule files from `ai/rules/core/` | Generated by `shooter_ensure-rules.sh` |
| `project-shotfiles/` | Per-theme shotfiles for nvim shot workflow | Human / `shooter:add-theme` |
| `tmp/` | Temporary files (git-ignored) | Transient |
